Download Rufin

Available for Linux, Windows, macOS and Android. Pick your platform below.

Linux

Flatpak

Works on any distribution and keeps Rufin up to date through Flathub.

Get it on Flathub 
flatpak install flathub app.rufin.rufin

Fedora

Available for Fedora 44 and 45 via COPR.

sudo dnf copr enable screwyy/rufin
sudo dnf install rufin

Arch Linux (AUR)

Latest binary release:

yay -S rufin-bin

Or build from the latest source:

yay -S rufin-git

Nix

Rufin is in nixpkgs. Run it without installing:

nix run nixpkgs#rufin

Or add it to your profile:

nix profile install nixpkgs#rufin

You can also run main or a specific release:

nix run github:rufin-app/rufin/master
nix run github:rufin-app/rufin/vX.Y.Z

Gentoo

Available in the karioverlay repository. Issues with the ebuild should go to the overlay maintainer.

First, install eselect-repository:

emerge --ask app-eselect/eselect-repository

Then add and sync the overlay:

sudo eselect repository add karioverlay git https://git.fumo.pet/kariga/karioverlay
sudo emaint sync -r karioverlay

Add one of these lines to /etc/portage/package.accept_keywords:

media-sound/rufin ~amd64
Latest stable version, built from source 
media-sound/rufin **
Latest git commit

Finally, emerge the package:

emerge -av media-sound/rufin

Windows

Installer

Download the .exe installer from the latest GitHub release.

Download for Windows

Turn on Automatic updates in General preferences to have Rufin install available updates when it starts, or click Update in Version History on the latest release.

macOS

Homebrew

Homebrew Cask is the primary way to install Rufin on macOS.

brew install --cask screwys/tap/rufin

Turn on Automatic updates in General preferences, or click Update in Version History on the latest release.

Disk image

Download the .dmg directly. Note that you will have to update Rufin manually.

Download .dmg

Android

Obtainium

Rufin for Android is installed and kept up to date with Obtainium. Open the button below on your phone, or add the repository URL in Obtainium yourself.

Get it on Obtainium 
https://github.com/rufin-app/rufin

Requires Android 7.0 or newer.

Build from source

Building natively requires Rust 1.96+, CMake 3.25+, Ninja, pkg-config, GTK 4.20+, libadwaita 1.9+ and GStreamer 1.26+. 

git clone https://github.com/rufin-app/rufin.git
cd Rufin
just build
just debug

Prefer to keep dependencies off your system? Use the Linux development container (Docker or Podman): 

just container setup
just build
