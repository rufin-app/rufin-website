# Installation

Rufin is a player that's main case is to listen to music from sources such as local files or any source listed on the [sources list](/docs/sources).

After making sure, that the music you want to listen to, is on a supported source, check out the [downloads page](/download).

*⚠️ If your OS is not supported on the downloads page, please file an issue on [Github](https://github.com/rufin-app/rufin)*
