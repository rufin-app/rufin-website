# Contributing

Rufin is free and open source, and there are several ways to help out.

## Report bugs and request features

Found a bug, or missing a feature? File an issue on
[GitHub](https://github.com/screwys/Rufin/issues). Please check first that it
hasn't already been reported.

## Contribute code

Fix bugs or add features by opening a pull request on
[GitHub](https://github.com/screwys/Rufin). Before you start, read the
[contributing guide](https://github.com/screwys/Rufin/blob/main/CONTRIBUTING.md),
and see the [build instructions](https://github.com/screwys/Rufin#building-locally)
to get Rufin running from source.

## Translate

Help bring Rufin to your language on
[Weblate](https://hosted.weblate.org/projects/rufin/app/). No coding needed.

## Donate

If you would like to support Rufin financially, see the [donate page](/donate).
