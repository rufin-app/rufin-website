# Navidrome

Connect Rufin to a [Navidrome](https://www.navidrome.org/) server.

- **Favorites, ratings and playlists:** stored on the server
- **Metadata editing:** through matched local files
- **Also:** radio, public share links

Navidrome speaks the [OpenSubsonic](/docs/sources/opensubsonic) API, so everything
on that page applies here too.

You can configure both a local and a public address for the server.
