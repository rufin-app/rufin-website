# Sources

Rufin can play music from these sources. Pick one to see what it supports.

| Source | Favorites, ratings and playlists | Metadata editing |
| --- | --- | --- |
| [Local Library](/docs/sources/local) | Kept by Rufin | Written to the files |
| [WebDAV / Nextcloud](/docs/sources/webdav) | Kept by Rufin | Written to the files |
| [Samba](/docs/sources/samba) | Kept by Rufin | Written to the files |
| [Jellyfin](/docs/sources/jellyfin) | On the server | Over the server API |
| [Emby](/docs/sources/emby) | On the server; ratings kept by Rufin | Over the server API |
| [Navidrome](/docs/sources/navidrome) | On the server | Through matched local files |
| [OpenSubsonic](/docs/sources/opensubsonic) | On the server | Through matched local files |
| [Plex](/docs/sources/plex) | On the server; favorites kept by Rufin | Over the server API |

Downloaded tracks, and tracks of a server matched to local folders, play from disk
while activity still goes to the server. You can also configure a local and public
address for a server.
